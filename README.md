# DS Lumora — Premium Website

Built from the supplied DS Lumora media pack.

## Run
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

All supplied JPGs are included under `public/media/`.
Instagram CTAs point to `https://www.instagram.com/ds_lumora/`.

The uploaded ZIP contained 26 JPG photos and no video files, so the current version uses the full photo collection. Video sections can be added directly once video files are supplied.
